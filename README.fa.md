# NetMon

**مانیتور ترافیک، فایروال و پنل وب نئونی برای سرورهای لینوکس**

ترافیک به تفکیک پورت، پروتکل و کشور، با شمارنده‌های دقیق کرنل، تاریخچهٔ ۳۰روزه
و فایروالی که از مرورگر کنترل می‌شود. فقط پایتون استاندارد + SQLite.

## امکانات

- **سرعت زنده**، هر ثانیه یک‌بار، به‌همراه رکورد بیشترین سرعت دانلود و آپلود و زمانش.
- **تاریخچه**: ۲۴ ساعت آخر با دقت ۵ ثانیه، ۳۰ روز به‌صورت ساعتی، و جمع روزانهٔ ماه.
- **تفکیک همهٔ پروتکل‌ها**: TCP، UDP، ICMP، GRE، ESP، SCTP و بقیه؛ هر کدام با دانلود، آپلود، پکت، تعداد درخواست و پیک سرعت.
- **پورت‌ها**: دانلود و آپلود، تعداد درخواست و پیک سرعت هر پورت، جدا برای ورودی (سرویس‌های روی سرور) و خروجی (پورت‌هایی که سرور به آن‌ها وصل می‌شود). پرترافیک‌ترین، پردرخواست‌ترین و سریع‌ترین پورت جدا نشان داده می‌شوند.
- **کشورها با پرچم**: رتبه‌بندی برای یک ساعت، امروز، ۲۴ ساعت، هفته و ۳۰ روز، نمودار روند، و لیست زندهٔ IPهای وصل با دکمهٔ بلاک.
- **فایروال**: بستن پورت تکی یا بازه، باز کردن یک پورت وسط بازهٔ بسته، توقف یا حذف قانون، بلاک IP، کلید SSH، و محافظت در برابر فلود (اختیاری).
- **پورت‌های معروف** دسته‌بندی‌شده بر اساس کاربرد، با کلید روشن/خاموش و نشانگر وقتی سرویسی روی آن پورت در حال اجراست.
- **نمودارهای دقیق**: با نگه‌داشتن ماوس عدد دقیق دیده می‌شود، با کشیدن ماوس زوم می‌شود، و با دابل‌کلیک برمی‌گردد.
- **حالت شب و روز**، سازگار با موبایل، و بدون نیاز به CDN بعد از نصب.
- **سبک**: یک سرویس، حدود ۲۵ مگ رم، چند مگ فضای دیسک، بدون پکیج pip.

## نصب

روی Ubuntu 20.04 به بالا یا Debian 11 به بالا:

<div dir="ltr">

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/ByeCoder/netmon/main/get.sh)"
```

</div>

یا از روی کلون:

<div dir="ltr">

```bash
git clone https://github.com/ByeCoder/netmon.git
cd netmon
sudo bash install.sh
```

</div>

نصب‌کننده:

1. پکیج‌های `python3`، `iptables`، `conntrack` و `iproute2` را نصب می‌کند. اگر apt قفل باشد، صبر می‌کند و اگر گیر کرده باشد آزادش می‌کند.
2. **یوزر و رمز ادمین** را می‌پرسد.
3. به‌صورت اختیاری IPهایی را می‌پرسد که هیچ‌وقت نباید بلاک شوند، مثل سرور تانل یا IP خودت.
4. پورت **8080** را برای پنل باز می‌کند و هیچ پورت دیگری را نمی‌بندد.
5. سرویس `netmon` را بالا می‌آورد و فونت‌ها و دیتابیس کشورها را در پس‌زمینه دانلود می‌کند.

بعد از نصب: `http://IP-سرور:8080`

نصب بدون سؤال:

<div dir="ltr">

```bash
sudo NETMON_USER=admin NETMON_PASS='a-long-password' NETMON_PORT=8080 bash install.sh
```

</div>

اجرای دوبارهٔ نصب‌کننده برنامه را به‌روز می‌کند و تنظیمات، قوانین و تاریخچه را نگه می‌دارد. نسخهٔ ۱ هم خودکار ارتقا داده می‌شود.

## دستورها

| دستور | کار |
|---|---|
| `sudo netmon status` | وضعیت و چیزهایی که اندازه‌گیری می‌شود |
| `sudo netmon passwd` | عوض کردن یوزر یا رمز ادمین |
| `sudo netmon unblock-all` | اضطراری: برداشتن همهٔ بلاک‌ها و محدودیت فلود |
| `sudo netmon geoip-update` | دانلود دیتابیس کشورها با نمایش پیشرفت (`--no-ipv6` کم‌حجم‌تر) |
| `sudo netmon geoip-import v4.csv [v6.csv]` | ساخت دیتابیس کشورها از فایل CSV دستی |
| `sudo netmon fw-apply` | اعمال دوبارهٔ قوانین فایروال |
| `journalctl -u netmon -f` | لاگ |
| `sudo bash uninstall.sh` | حذف کامل و پاک کردن همهٔ قوانین NetMon |

## چطور اندازه می‌گیرد

| چه چیزی | منبع | دقت نگهداری |
|---|---|---|
| کل دانلود و آپلود، سرعت زنده، پیک یک‌ثانیه‌ای | `/proc/net/dev` هر ثانیه | ۵ ثانیه برای ۲۴ ساعت، ساعتی برای ۳۰ روز |
| هر پروتکل: حجم، پکت، درخواست، پیک | قوانین شمارندهٔ iptables در جدول `mangle` | ۱ دقیقه / ساعتی |
| هر پورت: دانلود، آپلود، درخواست، پیک | قوانین شمارندهٔ هر پورت، که خودکار از پورت‌های در حال گوش دادن و پرکارترین پورت‌ها انتخاب می‌شوند | ۱ دقیقه / ساعتی |
| درخواست‌ها | شمارندهٔ اتصال‌های `NEW` در کرنل (دقیق) | مثل بالا |
| کشورها | جدول conntrack هر ۱۰ ثانیه، با دیتابیس آفلاین | ۱ دقیقه / ساعتی |

- قوانین شمارنده هیچ ACCEPT یا DROP ندارند، پس هیچ تأثیری روی ترافیک نمی‌گذارند.
- شمارش روی کارت شبکهٔ اینترنت انجام می‌شود، پس IPv4، IPv6 و ترافیک فورواردشدهٔ تانل همه حساب می‌شوند.
- دیتابیس کشورها [geo-whois-asn-country](https://github.com/sapics/ip-location-db) (مالکیت عمومی) است که به حدود ۱ تا ۲ مگ فشرده می‌شود و ماهی یک‌بار خودکار به‌روز می‌شود.

## فایروال

NetMon فقط در زنجیره‌های مخصوص خودش (`NM_*`) می‌نویسد و قوانین خودت در iptables، ufw یا nftables را دست نمی‌زند. همهٔ قوانین بعد از ریبوت هم می‌مانند.

- **پیش‌فرض همه‌چیز باز است.** هیچ پورتی بسته نمی‌شود مگر خودت ببندی.
- **بستن** پورت تکی یا بازه، برای ورودی، خروجی یا هر دو، و برای TCP، UDP یا هر دو. قوانین را می‌شود موقتاً متوقف کرد.
- **باز کردن یک پورت** وسط بازهٔ بسته، مثلاً بستن 10000 تا 20000 ولی باز نگه داشتن 12345.
- **کلید SSH**: بستن پورت 22 فقط جلوی ورود جدید را می‌گیرد و نشست‌های باز قطع نمی‌شوند. IP خودت را در «Never block» بگذار تا SSH برای خودت باز بماند.
- **بلاک IP یا رنج IP** در هر دو جهت، حتی مستقیم از لیست اتصال‌های زنده.
- **محافظت در برابر فلود** (پیش‌فرض خاموش): تعداد اتصال جدید از هر IP را محدود می‌کند. IPهای مجاز و پورت‌های تانل مستثنا هستند.
- **پورت پنل هیچ‌وقت بسته نمی‌شود**، پس نمی‌توانی خودت را بیرون کنی.
- قوانین ورودی قبل از NAT اجرا می‌شوند، پس پورت‌های فورواردشده به تانل یا داکر را هم پوشش می‌دهند. اتصال‌های برقرار و جواب‌های اتصال‌های خود سرور هیچ‌وقت قطع نمی‌شوند.

## تنظیمات

فایل `/etc/netmon/config.json`، و بعد `sudo systemctl restart netmon`.

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `web_port` | `8080` | پورت پنل |
| `web_host` | `0.0.0.0` | با `127.0.0.1` پنل فقط از طریق تانل SSH در دسترس است |
| `interfaces` | `[]` | کارت‌های شبکهٔ اندازه‌گیری؛ خالی یعنی کارت اینترنت |
| `poll_interval` | `5` | فاصلهٔ نمونه‌گیری ترافیک (ثانیه) |
| `bucket_seconds` | `60` | دقت تاریخچهٔ پورت، کشور و پروتکل |
| `flush_interval` | `30` | فاصلهٔ نوشتن در دیتابیس؛ بیشتر یعنی فشار کمتر روی دیسک |
| `retention_fine_hours` | `24` | مدت تاریخچهٔ ریز |
| `retention_hourly_days` | `30` | مدت تاریخچهٔ ساعتی |
| `max_server_ports` / `max_client_ports` | `64` / `32` | تعداد پورت‌هایی که شمارندهٔ جدا دارند |
| `trust_proxy` | `false` | پذیرفتن `X-Forwarded-For` پشت ریورس‌پراکسی خودت |

## امنیت

پنل با دسترسی root اجرا می‌شود، چون iptables را مدیریت می‌کند، و پیش‌فرض روی پورت 8080 از اینترنت در دسترس است.

- رمز با PBKDF2-SHA256 هش می‌شود.
- نشست‌ها کوکی امضاشدهٔ HttpOnly و SameSite=Strict هستند و با عوض کردن رمز باطل می‌شوند.
- بعد از ۵ رمز اشتباه، آن IP برای ۱۰ دقیقه قفل می‌شود.
- همهٔ درخواست‌های تغییردهنده هدر مخصوص لازم دارند (محافظت CSRF) و Content-Security-Policy سخت‌گیرانه ارسال می‌شود.

برای امنیت بیشتر، پنل را پشت HTTPS (nginx یا Caddy) بگذار، یا روی localhost ببند و با تانل SSH وصل شو:

<div dir="ltr">

```bash
ssh -L 8080:127.0.0.1:8080 user@your-server
```

</div>

## رفع مشکل

**خطای `Could not get lock /var/lib/apt/lists/lock`**: یک apt دیگر (معمولاً آپدیت خودکار) در حال اجراست. نصب‌کننده صبر می‌کند و اگر گیر کرده باشد آزادش می‌کند. دستی:

<div dir="ltr">

```bash
sudo systemctl stop unattended-upgrades apt-daily.service apt-daily-upgrade.service
sudo pkill -9 -x apt-get; sudo pkill -9 -x dpkg
sudo rm -f /var/lib/dpkg/lock-frontend /var/lib/dpkg/lock /var/lib/apt/lists/lock /var/cache/apt/archives/lock
sudo dpkg --configure -a
```

</div>

**کشورها Unknown نشان داده می‌شوند**: دیتابیس کشورها هنوز دانلود نشده. با `journalctl -u netmon-geoip -f` پیشرفتش را ببین، یا `sudo netmon geoip-update` را بزن. اگر از روی سرور به هیچ میرری دسترسی نیست، فایل `geo-whois-asn-country-ipv4-num.csv` را از [jsDelivr](https://cdn.jsdelivr.net/npm/@ip-location-db/geo-whois-asn-country/) روی سیستم دیگری دانلود کن، روی سرور بفرست و بزن: `sudo netmon geoip-import geo-whois-asn-country-ipv4-num.csv`

**SSH بسته شد و دسترسی نداری**: از کنسول وب ارائه‌دهندهٔ سرور وارد شو و `sudo netmon unblock-all` را بزن.

**عددهای پورت صفر است**: `sudo netmon status` را بزن. شمارش حجم پورت و پروتکل به iptables نیاز دارد. در بعضی کانتینرها (LXC، OpenVZ) کرنل اجازه نمی‌دهد و NetMon فقط جمع کل و تعداد اتصال‌ها را نشان می‌دهد.
